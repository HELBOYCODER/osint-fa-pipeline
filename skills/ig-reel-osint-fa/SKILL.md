# پیل‌لاین OSINT فارسی (تست‌شده) — نسخه ایجنت

وقتی کاربر لینک ریل اینستاگرام/عکس فرستاد، این چرخه را اجرا کن:

## چرخه
1. **دانلود:** `yt-dlp --no-playlist -o "ig_reel.%(ext)s" "<URL>"` + متادیتا با `-J`
2. **استخراج:** `ffmpeg` → audio.wav (16k mono) + فریم‌ها (`fps=1/10`)
3. **EXIF:** `exiftool` — GPS/دستگاه/زمان. خالی = عادی، ادامه بده
4. **بینایی:** هر فریم → سؤال باز + سپس **کراپ 3x با LANCZOS روی هر تابلو/متن** (`scripts/zoom.py`) → متن فارسی بخوان → **وب‌سرچ آدرس رسمی**
5. **صوت:** `HF_ENDPOINT=https://hf-mirror.com` + `scripts/tr.py audio.wav` (venv: `~/.venvs/osint`، faster-whisper، av==12.3.0)
6. **لوکیت:** EXIF → متن تابلو → فاز ماه (`scripts/moon.py`، UTC!) → جستجوی معکوس (Lens/Yandex/PimEyes)

## قوانین
- OCR غلط = لوکیت غلط؛ اگر مطمئن نیستی، به کاربر بگو حدس نزن
- عکس خصوصی در reverse search نمی‌آید — وقت هدر نده
- IRAN: پلاک خودرو کد استان را در مربع راست دارد
- شواهد محیطی ثبت کن: معماری، درخت (چنار=شهر ایران)، پلاک در، آبخوری/سقاخانه

## گزارش به کاربر
متادیتا + توصیف تصویری + متن صوت + سرنخ‌های لوکیت + سؤالات تکمیلی (زمان/جهت/شهر).
